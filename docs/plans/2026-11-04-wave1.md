# Go School, волна 1: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Рабочий локальный сайт курса со всей программой (77 уроков в навигации) и полностью написанными модулями 00-04 и уроками 11.1-11.4, с проверяемой домашкой.

**Architecture:** VitePress-сайт в `site/`, единый манифест курса `course.ts` питает сайдбар и карту роадмапа; урок без md-файла показывается как «скоро». Домашка в отдельном Go-модуле `homework/`: заготовки красные, эталоны в `.solutions/` накладываются скриптом. Контент пишут параллельные исполнители по общему контракту `AUTHORING.md`.

**Tech Stack:** VitePress 1.x, Vue 3, TypeScript, vitest (только для `progress.ts`), Go 1.27.3.

**Spec:** `docs/design.md`

## Global Constraints

- Тексты на русском. Символ «—» запрещён везде (контент, код, комментарии).
- Go 1.27; факты о версиях 1.21-1.27 сверять с `go doc` и go.dev/doc/go1.N, непроверяемое не писать.
- У каждого источника пометка `RU` или `EN`, русские первыми; ссылка должна открываться.
- Шаблон урока (порядок блоков) из `docs/design.md`, раздел «Шаблон урока».
- Заготовка домашки компилируется и падает; эталон проходит `go test -race`; `go vet` чистый.
- Светлая и тёмная темы. Шрифты и палитра не из списка штампов (Inter, Roboto, Geist, Unbounded, Onest, Golos, Manrope, Playfair).
- Запуск только локально: `cd site && pnpm dev`.

## Review Focus

1. Импорт битого или чужого JSON прогресса: отклонить с сообщением, текущий прогресс не трогать.
2. localStorage недоступен или старая версия схемы: сайт рендерится, прогресс живёт в памяти или мигрирует.
3. Слабый тест домашки, который проходит на заготовке: `check-stubs.sh` должен это поймать.
4. Недетерминированные конкурентные задачи: эталоны гоняются с `-race -count=5` без флейков.
5. Урок есть в манифесте, а md нет: в сайдбаре и на карте он «скоро», без ссылки в 404.

### Task 2: Логика прогресса (TDD)

**Files:** `site/.vitepress/theme/progress.ts`, `progress.test.ts`, `site/package.json`.

**Produces:**
```ts
type Progress = { v: 1; lessons: Record<string, { done: boolean; at: string }>; hw: Record<string, boolean> }
load(storage: Storage | null): Progress          // null/битое/чужая версия → пустой Progress
save(storage: Storage | null, p: Progress): void // молча no-op без storage
toggleLesson(p, id, now): Progress               // чистые функции, без мутации входа
toggleHw(p, id): Progress
exportJson(p): string
importJson(text: string): { ok: true; p: Progress } | { ok: false; error: string }
```
- [ ] Тесты: пустой storage; битый JSON → пусто; `v: 99` → пусто; toggle не мутирует вход; importJson отклоняет не-объект, чужую версию, `lessons` не того типа, с понятной ошибкой на русском; export→import круговой.
- [ ] RED, затем реализация, затем `pnpm vitest run` GREEN.
- [ ] Commit.
